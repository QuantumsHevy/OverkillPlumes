# Changelog
All notable user-facing changes to Overkill Plumes are documented in this file. This mod is compatible with Kerbal Space Program 1.12 unless noted otherwise. Version numbers should follow semantic versioning.

## v0.2.0
### Added
- Added a plume switcher to every supported engine. Right-click the engine in the VAB/SPH (or in flight) to choose between the Overkill exhaust and the original plume.
- Added an Overkill plume for the LV-N 'Nerv' Atomic Rocket Motor, including a [Restock](https://github.com/PorktoberRevolution/ReStocked)-aware patch.
- Added an Overkill plume for the Kerbodyne KR-2L+ 'Rhino' Liquid Fuel Engine, also including a [Restock](https://github.com/PorktoberRevolution/ReStocked)-aware patch.
- Added an Overkill plume for [Far Future Technologies](https://github.com/post-kerbin-mining-corporation/FarFutureTechnologies)' A-834M 'Frisbee' Antimatter Torch Engine, including an extra "ISV Venture Star" plume option if [Interstellar Plumes](https://spacedock.info/mod/4110/Interstellar%20Plumes) is also installed.
- Added a bit of original in-universe lore to several plume descriptions (and some related, original flags).
### Changed
- [Waterfall](https://github.com/KSPModStewards/Waterfall), [ModuleManager](https://github.com/sarbian/ModuleManager), and [B9PartSwitch](https://github.com/blowfishpro/B9PartSwitch) are now Overkill's core dependencies. [Stock Waterfall Effects](https://github.com/KnightofStJohn/StockWaterfallEffects) and [Far Future Technologies](https://github.com/post-kerbin-mining-corporation/FarFutureTechnologies) are supported mods/compatibility layers, instead (SWE unlocks the stock Nerv and Rhino plumes, and FFT unlocks its own NSWR and Frisbee plumes).

## v0.1.0
### Added
- Added an Overkill plume for [Far Future Technologies](https://github.com/post-kerbin-mining-corporation/FarFutureTechnologies)' X-42 'Niven' Nuclear Salt Water Rocket Engine.
- Added an Overkill plume for [Far Future Technologies](https://github.com/post-kerbin-mining-corporation/FarFutureTechnologies)' X-2 'Heinlein' Nuclear Salt Water Rocket Engine.
